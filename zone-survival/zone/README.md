# Зона виживання (C++17 + raylib)

Гра, що поєднує **Infection Free Zone** (колонія: вцілілі з професіями, база, оборона від орд)
та **Project Zomboid** (детальне виживання одного героя: потреби, інвентар, шум, інтер'єри, навички).
Ізометрична 2.5D-графіка, місто генерується процедурно (96×96 клітинок, до 3 поверхів).

## Запуск без встановлення програм (GitHub)

1. Створіть безкоштовний акаунт на github.com і новий репозиторій, завантажте в нього вміст цієї теки (кнопка «Add file → Upload files»; тека `.github` теж має потрапити).
2. У репозиторії: **Settings → Pages → Source: GitHub Actions**.
3. Вкладка **Actions** → «Збірка» → зачекайте ~5–10 хв.
4. Готово: у «Settings → Pages» з'явиться посилання — гра відкривається просто в браузері (Chrome/Edge/Firefox, клікніть по вікну, щоб пішов звук).
   Також у запуску Actions є завантаження `zone-Windows`, `zone-macOS`, `zone-Linux` — готові версії для запуску.

У браузерній версії збереження живе в сховищі браузера.

## Збірка вручну

Потрібні: компілятор C++17, CMake ≥ 3.14, інтернет для першого збирання (CMake сам завантажить raylib 5.0).

```bash
cmake -B build
cmake --build build --config Release
./build/zone            # Windows: build\Release\zone.exe
```

Linux: для raylib потрібні пакети X11/OpenGL (`sudo apt install libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev libgl1-mesa-dev`).
Шрифт з кирилицею (`assets/DejaVuSans.ttf`) копіюється поруч із виконуваним файлом автоматично.
Запускайте гру з теки, де лежить `assets/` (або з `build/`).

Тести симуляції без вікна: `cmake -B build -DZONE_TESTS=ON && cmake --build build && ./build/test_sim2`.

## Що всередині

* **Герой:** голод, спрага, втома, витривалість, здоров'я, кровотеча, інфекція (48 год після зараження), настрої (moodles), вага рюкзака.
* **Професії:** поліцейський, тесля, медсестра, фермер, злодій — різне спорядження і стартові навички.
* **Навички (13):** фітнес, сила, спринт, легка хода, скритність, тупа/холодна/вогнепальна зброя, теслярство, кулінарія, землеробство, перша допомога, збирання — ростуть від використання.
* **Шум:** кроки, удари, постріли, злам дверей приваблюють зомбі; навколо героя видно кільце шуму.
* **Зомбі:** ходяче, біг, здоровило; зір (конус, ніч), слух, переслідування, злам дверей і барикад, орди (з 3-го дня кожні 3 дні), подія з гелікоптером.
* **Будинки:** кімнати з меблями-контейнерами, сходи, замкнені двері, вікна; розріз стін, коли герой всередині; туман війни з пам'яттю карти.
* **Колонія:** знайдіть вцілілих (жовті мітки), вербуйте (E). Роботи: іти за героєм, відпочивати, пост, збирати припаси, садити/збирати, будувати. Спільний склад — скрині на базі.
* **Будівництво:** стіни, двері, скрині, ліжка, грядки, вогнище, бочка з водою; плани можуть будувати колоністи.
* **Крафт:** бинти, дошки, бита, страви біля вогнища, аптечка.
* Усі звуки синтезуються в коді, окремих аудіофайлів немає.

## Структура

```
src/world.*    світ, генерація міста, A*, видимість
src/items.*    предмети, навички, професії
src/game.*     гравець, потреби, дії, інвентар, будівництво
src/zombie.cpp бій, шум, ШІ зомбі, події
src/colony.cpp колоністи, роботи, грядки
src/save.cpp   збереження/завантаження
src/render.*   ізометричний рендер (raylib)
src/ui.*       HUD і панелі
src/audio.*    процедурний звук
src/main.cpp   вікно і цикл
tools/         тести без вікна, заглушка raylib для перевірки рендера
```
